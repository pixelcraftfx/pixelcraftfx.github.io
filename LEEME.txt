CÓMO REEMPLAZAR LOS ARCHIVOS
1. Entra a https://github.com/pixelcraftfx/pixelcraftfx.github.io
2. Pulsa Add file > Upload files.
3. Selecciona y sube estos CINCO archivos A LA RAÍZ:
   index.html, trabajos.html, style.css, favicon.svg, favicon.ico
4. Si GitHub pregunta, confirma el reemplazo de los existentes.
5. Pulsa Commit changes.
6. Espera que GitHub Pages termine de publicar (Settings > Pages, o Actions).
7. Abre https://pixelcraftfx.github.io/ y luego
   https://pixelcraftfx.github.io/trabajos.html
8. Si ves una versión anterior, recarga con Ctrl+F5 o en incógnito.

AGREGAR VIDEOS
Abre trabajos.html en GitHub y busca:
    INICIO TARJETA DE VIDEO: DUPLICA DESDE AQUÍ
Copia desde <article class="video-card work-video-item"> hasta el
</article> correspondiente y pégalo justo debajo, dentro de
<div class="work-video-list">. Cambia el título, descripción y miniatura.
En el mismo HTML tienes instrucciones comentadas para usar enlaces a YouTube.
